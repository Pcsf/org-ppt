* Foundations

** What this is

One Org file in, one =.html= file out. Open it in any browser, press =f=, and
you are presenting. No server, no CDN, no runtime install on the machine that
shows the slides.

#+ATTR_PPT: :fragment t
- Stylesheet and runtime are inlined
- Images are embedded as data URIs
- The deck still works from a USB stick in an offline meeting room

#+BEGIN_NOTES
Speaker notes live here. Press =s= during the talk to open the notes panel
with the timer. The audience never sees this text.
#+END_NOTES

display equation gets its own line:

\begin{equation}

KaTeX ships inside =org-ppt=. This slide was typeset at export time, so it
carries no script and no LaTeX, and renders offline on any machine.

** Driving the deck

- =f= fullscreen, =o= overview, =b= blank the screen

* Making the deck yours

** Driving it from a template

The title slide's background did not come from an image file. It was read out
of =brand.potx=, a PowerPoint template sitting next to this deck:

#+BEGIN_EXAMPLE
,#+ORG_PPT_TITLE_BG: brand.potx
,#+ORG_PPT_TITLE_BG_DIM: 0.2
#+END_EXAMPLE

org-ppt walks the package — first slide, then layout, then master — and takes
the largest picture it finds. That template also holds a small logo, which is
exactly the thing a naive "first image wins" would have picked instead.

=M-x org-ppt-list-pptx-images= lists what a template holds, and
=brand.potx::ppt/media/titleBackground.png= names one outright.

#+BEGIN_NOTES
Only the background picture is imported. Layouts, placeholders, fonts and text
stay in PowerPoint; =#+ORG_PPT_ACCENT= is how a deck matches a brand colour.
#+END_NOTES

** Text that fits the frame                                          :fit:

This slide carries more than a slide should, and the deck is exported with
=#+ORG_PPT_AUTOFIT: t=, so the runtime measures it and shrinks the type until
it fits rather than clipping whatever ran past the bottom edge. Every other
slide in this deck already fits, so every other slide is left alone at the
deck size — the deck does not drift into a dozen different type sizes.

Autofit only ever shrinks, and never below half the deck size, because a
slide nobody can read from the back of the room is not a fit. It measures
once the fonts and images have settled, which is why a slide that fits in a
fallback face still fits in the real one.

Set =#+ORG_PPT_FONT_SCALE: 0.9= to resize the whole deck by hand instead, or
put =:PPT_FONT_SCALE:= in a slide's property drawer to resize one slide. The
three are the same knob: autofit is the runtime turning it for you, and
=:fit:= or =:nofit:= on a headline overrules the deck-wide setting.

None of this is special markup. These are ordinary paragraphs on an ordinary
slide, and there are simply more of them than a 1280 by 720 frame holds at
26 px. Compare the type here with the slide that follows, which is set at the
deck size because it had room to spare.

Before this version the last two paragraphs of this slide were not smaller.
They were gone — clipped at the bottom edge, with nothing on screen and
nothing in the export to say that a third of the slide had been dropped.

   :PROPERTIES:

   :END:

This slide carries =:PPT_FONT_SCALE: 0.62= in its property drawer, so it is
set at just under two thirds of the deck size while every other slide is
unchanged.

Useful for a dense table, a long code listing, or a wall of references you
want on one slide and do not expect the room to read from the back.

*** Everything scales together

Headings, body text, =inline code=, tables and captions are all fixed ratios
of one base size, so there is a single number to turn.

** Handouts carry the notes

=Ctrl+P= prints one page per slide. With =#+ORG_PPT_PRINT_NOTES: t= in the
header, each slide's speaker notes are printed in a band underneath it, so
the handout is the deck plus what you were going to say about it.

- the page grows to hold the band, so it is still one page per slide
- the screen presentation is untouched; the room never sees the notes
- raise =#+ORG_PPT_PRINT_NOTES_HEIGHT= for a talk with long notes

The page also follows the deck's own aspect ratio now. A =4:3= deck prints
=4:3= pages; it used to print =16:9= whatever the stage said.
